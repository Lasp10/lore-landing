Questions about Lore

What is Lore?

Lore is an AI teammate that lives in a team group chat. It uses the conversation as context, remembers decisions, helps with open work, and reports results back in the same thread.

Is Lore an AI agent for Slack?

Yes. Lore runs inside Slack and can turn a message into multi-step work such as research, browser tasks, documents, checklists, and follow-ups. Actions that book, buy, send, or post require approval.

How is Lore different from a Slack chatbot?

A basic chatbot waits for a prompt and returns text. Lore is built to remember team context, follow work across messages, use tools such as a web browser, and return completed work to the conversation.

Can Lore remember past Slack decisions?

Lore keeps durable team memory so the group can ask why a decision was made and recover the relevant conversation later.

Does Lore take actions without approval?

Lore can prepare and perform internal work from the conversation. External actions such as sending, posting, booking, or buying use approval gates so a team stays in control.
